# 本地快传 LanPass

两台电脑在同一个路由器（或同一个 Wi-Fi）下互传文件的小工具。**不用数据线、不用 U 盘、不经过互联网。**

一份 exe 通吃 **Windows 7 SP1 / 8 / 8.1 / 10 / 11**，32 位与 64 位系统通用，无需安装 Python、.NET 或任何运行环境。

## 特点

- **零依赖**：纯 Python 标准库 + tkinter 实现，不引入任何第三方包
- **默认加密**：内置 HTTPS（自签证书，运行时自动生成），同一网络下抓包也看不到内容
- **访问令牌**：接收端必须填对 6 位数字令牌才能连接
- **免安装**：绿色软件，不写注册表、不装系统服务，删掉文件即卸载
- **换机搬机**：旧电脑的数据一次性搬到新电脑 —— 全程局域网直传，不经过云盘、不经过任何第三方服务器
- **跨网段**：支持 UPnP 端口映射与反向接入隧道，不在同一个路由器下也能传
- **断点续传**：传输中断后重新发起，从已完成位置继续
- **多连接并行**：大文件自动分段并行传输，实测提速 3.9～4.8 倍
- **双栏文件浏览器**：本机 / 远端两栏对照，支持新建、重命名、删除、拖放
- **三种视图**：列表 / 大图标 / 平铺，后两者给图片显示缩略图（可见区懒加载）

## 适用场景

**· 换新电脑 / 重装系统**
把旧机器上的桌面、文档、照片、下载目录整个搬到新机器 —— 两台机器接同一个路由器
（或者一根网线直接对接）就能传。数据从旧机器直接落到新机器，不上传、不下载、
不经云盘中转，也就没有"上传到一半家里断网"的尴尬。

**· 搬大文件 / 搬整机**
几十上百 GB 的资料、虚拟机镜像、录播视频：支持整目录传输、分段并行
（实测提速 3.9～4.8 倍），中途断了不用从头再来 —— 重新发起就从已完成的位置续上。

**· 两台机器之间日常互传**
不用数据线、不用 U 盘，也不用发微信传文件（微信有大小限制、会压缩）。
一次把 IP 和 6 位令牌告诉对面，剩下的拖拽就行。

**· 系统重装前抢救数据**
系统还没重装、数据都还在原机器上的时候，先把该留的东西拉到新机器或外置盘，
比重装完再去找文件稳妥。

> 换机场景下建议**插网线**：几百 GB 的量，Wi-Fi 的稳定性和实际速率都吃亏。
> 传输过程中不要休眠、不要关窗口；断点续传随时可以接上。

## 快速开始

1. **发送端那台**：双击 `LanPass.exe` → 选【发送端】→ 点【启动服务】
   记下界面上的 **本机 IP** 和 **访问令牌**（6 位数字）
2. **接收端那台**：双击 `LanPass.exe` → 选【接收端】
3. 点【扫描】→ 在下拉列表选中找到的发送端 → 点【确认填入】
   → 填入 6 位令牌 → 点【连接】

扫描不到就手工填写 IP / 端口 / 令牌。

### 常用启动参数

```bat
:: 只共享指定目录（默认共享全部磁盘）
LanPass.exe --roots "D:\资料"

:: 指定端口
LanPass.exe --port 8899
```

完整说明见 [`dist/操作手册.txt`](dist/操作手册.txt)（10 章 + 附录），
或 [`dist/使用说明-简明版.txt`](dist/使用说明-简明版.txt)（一页看完）。

```bat

```

也可以在资源管理器里双击 `start_gui.bat`。

## 安全说明

- 传输默认启用 HTTPS 加密，自签证书在首次运行时自动生成，**不随代码分发**
- 接收端必须提供正确的 6 位令牌
- 发送端默认**不允许**对方上传、**不允许**对方删除本机文件，需要手动开启
- 开启删除权限时会先弹安全确认；本机删除走回收站，远端删除需二次确认
- 建议只在可信网络（家里、公司内网）中使用
